# Security boundary

Treat this release as a public preview. Do not use it for high-stakes autonomous changes. AI actions are proposals until approved. The runtime supports only user-selected text file reads and explicitly reviewed file saves; arbitrary shell or computer-control commands are not exposed.

Do not post credentials, private workspace exports, or model-request logs in public issues. Report security issues privately through GitHub's repository security reporting when enabled, or contact the repository owner without disclosing sensitive material publicly.

Release signing, notarization, recovery/backup UX, independent security review, rate-limit hardening, and broader OS verification remain production-launch work.
