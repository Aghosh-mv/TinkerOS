Build a polished, production-quality desktop application called:

NIBRA BL BETTERLIFE

Tagline:
“Your private AI copilot for a better digital life.”

Nibra BL BetterLife is a local-first AI desktop companion that sits beside the user’s work like an intelligent copilot. The user connects either a cloud AI model or a local AI model, gives permission to selected apps and data sources, and then Nibra helps them understand their digital life, organize tasks, detect commitments, summarize important information, prepare actions, and improve their productivity.

This should feel like a serious future-facing product, not a simple chatbot, dashboard, or generic productivity app.

The product should combine:

- AI assistant
- Desktop sidecar
- Personal knowledge system
- Daily briefing
- Email and calendar intelligence
- Task and commitment tracking
- Computer-use automation
- Personal chief of staff
- Private digital-life workspace
- Agentic action preparation
- Local-first privacy controls

The product should be designed around trust, consent, clarity, and usefulness.

Important positioning:

Do not describe the application as secretly watching or spying on the user. Describe it as a consent-based personal operating layer that only accesses sources the user explicitly enables.

The user must always know:

- What Nibra can access
- What Nibra is currently reading
- What Nibra remembers
- What Nibra inferred
- What action Nibra wants to take
- Which model received the data
- Whether an action is only suggested, prepared, or executed

The visual design should be premium, calm, intelligent, modern, and memorable. Avoid generic SaaS design, generic purple gradients, boring cards, excessive rounded rectangles, and cluttered dashboards.

Use a distinctive visual language:

- Deep midnight blue, warm ivory, muted orange, electric cyan, and soft green
- Dark-primary interface with a refined light mode
- Subtle atmospheric gradients
- Thin technical lines
- Soft glowing data points
- Elegant information density
- Clear typography hierarchy
- Strong visual focus around “Today”
- Minimal but meaningful motion
- No unnecessary animations
- No childish robot graphics
- No excessive glassmorphism
- No fake futuristic clutter

The interface should feel like a combination of:

- Personal command center
- Calm executive assistant
- Mission control
- Premium note-taking workspace
- Private AI operating system

Use a strong display font for large headings and a highly readable sans-serif font for body text. Typography should feel intentional and premium.

The app must be responsive across desktop sizes and usable on smaller screens. The main target is desktop, but the layout should gracefully adapt to tablet and narrow windows.

SECURITY REQUIREMENTS

The app must:

- Never expose API keys in logs
- Never display API keys after saving
- Never execute high-impact actions automatically
- Require confirmation for sending, deleting, purchasing, sharing, or posting
- Keep an activity log
- Provide an emergency stop
- Support permission revocation
- Use explicit user consent
- Distinguish demo mode from real integrations
- Avoid claiming that local models guarantee privacy
- Explain that external providers may process data according to their own policies
