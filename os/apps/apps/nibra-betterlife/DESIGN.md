# Nibra visual system

User-directed midnight-blue primary interface, warm ivory text, muted orange actions, cyan intelligence accents, green progress. Restrained use of atmospheric gradients in the focus panel. Premium means calm hierarchy, useful density, clear labels, and honest states.

Body and controls use the platform sans-serif; greeting and empty-state headings use Georgia for a human editorial accent. Navigation is quiet, with a 232px sidebar and two-column Today layout. Hairline separators replace most cards. Radius 6px for controls, 9–12px for bounded surfaces. Native dialogs handle focus containment and Escape. Narrow windows collapse navigation and stack the content. All functional state is visible; no decorative loading simulations.

Color tokens are in src/style.css using OKLCH. Light mode changes the neutral and semantic ramps. Focus indication uses cyan. All motion is disabled under prefers-reduced-motion. The app icon is a typographic n with a small orange star, matching the in-app mark.
