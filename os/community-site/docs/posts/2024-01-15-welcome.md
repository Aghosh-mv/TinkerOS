# Welcome to the New TinkerOS Community Hub!

We're thrilled to launch the new **community.tinkeros.dev** — your central hub for everything TinkerOS community!

## What's New?

### 🏠 Centralized Community Hub
Everything community-related in one place:
- News and announcements
- Contribution guides
- Community showcases
- Support resources
- Governance information

### 📝 Blog & News
Stay up to date with:
- Release announcements
- Feature deep-dives
- Community spotlights
- Security advisories
- Event coverage

### 🤝 Contribution Made Easy
New contribution guides for:
- **Code contributors** - Kernel, apps, tools
- **Documentation writers** - Guides, tutorials, API docs
- **Designers** - Themes, icons, wallpapers, UI/UX
- **Translators** - Help TinkerOS speak your language
- **Testers** - Beta testing, hardware reports, QA

### 🎨 Community Showcase
Share and discover:
- Desktop setups and rice
- Custom workflows and scripts
- Theme collections
- Productivity setups

## Get Started

1. **Join the conversation** → [Discord](https://discord.gg/tinkeros)

3. **Read the docs** → [Documentation](https://docs.tinkeros.dev)
4. **Contribute** → [Contribution Guide](contribute/getting-started.md)
