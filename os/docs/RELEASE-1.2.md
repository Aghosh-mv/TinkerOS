# TinkerOS 1.2 — release notes

Bootable Ubuntu-based desktop distribution (jammy) with the TinkerOS kernel +
the 3 worlds (HACK / NORMAL / GAME) and the Searchie address engine baked in.

## Highlights

- **Real kernel features** inside the Linux source (`kernel/tinker/`, 27+
  modules): GameMode schedutil P-state boost (+ runtime sysfs knob), crash-safe
  gamemode boost reaping, thermal-scheduler integration, spec-gated fan
  dust-dislodger (`tinker-dust` refuses to shake until the fan envelope is
  calculated), battery/energy/coil-whine/display hints and more.
- **Searchie** (Tab+F7): whole-session memory engine — every file, terminal,
  email, browser and note is indexed as it happens; plain-phrase queries with a
  7-tier relax cascade (strict → phoneme → category+time), bloom + suffix-array
  infix lookup, LSH near-duplicate detection, markov completion in the overlay,
  `align` integrity auditor, `timeline`, and `optimize --burn`.
- **Three worlds**: HACK (kali-style toolkit), NORMAL (macOS-like lockdown:
  ufw/apparmor/firejail/keepassxc), GAME (Steam/Lutris/Proton + gamemode).
- **Full desktop**: Xfce, LibreOffice, GIMP, Blender, Firefox, Thunderbird,
  VLC, dev toolchain (gcc/make/python/cmake), kmod build deps.
- **Branded boot**: TinkerOS Plymouth splash + GRUB menu, custom distro
  identity (`ID=tinkeros`, 1.2).

## Boot

UEFI and BIOS (isolinux/grub) both supported; volume label `TinkerOS`;
casper live layout; safe-graphics menuentry included.
